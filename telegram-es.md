**De los datos abiertos al conocimiento compartido**
*Computación, automatización e inteligencia artificial para investigar y aprender*

**Miércoles 21 de octubre de 2026, 9:00 a. m. (hora de Venezuela, UTC−4).** Charla en línea. El enlace de conexión se anunciará aquí cuando lo confirme la organización.

¿Cuánto tiempo dedicamos a preparar herramientas, ordenar archivos, repetir cálculos o actualizar informes, antes de poder concentrarnos en lo que queremos investigar?

Esta charla en línea para el **Instituto de Ingeniería de Venezuela** propone una forma práctica de conectar esas tareas. Veremos cómo utilizar tecnologías accesibles para que estudiantes, docentes e investigadores puedan comenzar un proyecto, colaborar y producir resultados que otras personas puedan comprender, comprobar y reutilizar.

**Cada participante se llevará un repositorio listo para usar**, con datos de ejemplo, scripts sencillos e instrucciones para empezar a crear sus propios prototipos. Trabajaremos con tres ejercicios concretos: **analizar un archivo de datos, generar un gráfico y producir automáticamente un PDF a partir de un texto Markdown y una carpeta de imágenes**. Al modificar los datos, el texto o una fotografía, las automatizaciones correspondientes volverán a generar los resultados.

A partir de estos ejemplos, exploraremos cómo:

- **Organizar un proyecto reproducible:** conectar datos, código, notas y documentos, conservando las decisiones que explican cada resultado.
- **Trabajar con Git y GitHub:** guardar versiones, revisar cambios y colaborar sin perder el historial del trabajo.
- **Automatizar tareas repetitivas:** usar Python y GitHub Actions para ejecutar análisis y preparar gráficos e informes sin rehacer cada paso manualmente.
- **Aprovechar modelos de lenguaje:** comprender código, preparar borradores de scripts y mejorar documentación, comprobando siempre las propuestas y sus resultados.
- **Adaptar una solución a otros problemas:** convertir un ejemplo pequeño en el punto de partida de una tesis, una actividad docente o un proyecto científico o comunitario.

La charla conectará estas herramientas con experiencias de ATLAS Open Data, dirección de tesis, CoAfina, Creative Commons Venezuela, Los Topos Cósmicos, la propuesta LAGO Mérida y proyectos de cartografía. El propósito es acercar la infraestructura a las personas y aprovechar los recursos disponibles para fortalecer la investigación y la educación en Venezuela, conociendo sus posibilidades y límites.
