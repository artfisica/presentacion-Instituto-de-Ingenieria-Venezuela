# Imágenes para el documento

Coloca aquí tus imágenes PNG o JPG. En `ejemplos/informe.md`, utiliza una línea como:

```markdown
![Descripción y crédito de la imagen](../imagenes/mi-imagen.png)
```

Para empezar, reemplaza `actividad-atlas.jpg` por otra imagen con el mismo nombre, o cambia también la ruta en Markdown. Al subir el cambio a **tu** repositorio, la acción **03 - Crear PDF** vuelve a construir el documento, aunque no hayas cambiado el texto.

La imagen incluida procede del artículo de ATLAS sobre formación en Venezuela. Crédito: ATLAS Collaboration / CERN. Fuente y condiciones del material original: <https://atlas.cern/updates/blog/HEP-education-worldwide-with-atlas-open-data>.
