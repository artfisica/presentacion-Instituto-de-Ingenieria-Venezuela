# Aquí aparecen los resultados

Los scripts escriben `resumen.json`, `informe.html`, `grafico.png` e `informe.pdf` en esta carpeta. Se regeneran: no hace falta guardarlos en Git.

En GitHub Actions se descargan desde **Artifacts**, dentro de la ejecución correspondiente. La acción no modifica tus archivos ni crea commits. Los artefactos de estos ejercicios se conservan durante 14 días; puedes descargar una copia o volver a ejecutarlos.
